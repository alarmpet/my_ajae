# 성과 되먹임 (2026-11-14)

## 1. 모으기

```bash
python -X utf8 tools/post_metrics.py --dry    # 표만
python -X utf8 tools/post_metrics.py          # 표 + ledger/metrics.jsonl 에 오늘 줄 추가
```

- 스레드: views · likes · replies · reposts · quotes · shares. 인스타: reach · likes · comments · saved · shares.
- 매주 같은 요일(일요일 저녁)에 한 번. 글 나이가 다르면 비교가 틀어지므로 **올린 지 3일 이상 지난 글끼리만** 견준다.
- 권한 오류가 나면 그 칸은 「권한 없음」 — 숫자를 채우지 않는다.

## 2. 읽는 법

1. **스레드 답글에서 우리 것을 뺀다.** 이어지는 조각과 첫 댓글이 replies 에 잡힐 수 있다(L0001 의 replies 2 — 우리가 단 것이 둘이다. 남의 답글인지는 앱에서 눈으로 확인). 
2. **조회수가 먼저다.** 조회가 100 아래면 좋아요 · 댓글 비율은 뜻이 없다. 이 단계에서는 「조회가 어디서 갈렸나」만 본다.
3. 비교 축: 기둥(`pillar`) · 훅 틀(`hook`) · 앱 · 아침/저녁 · 카드 종류(코드 화면 / 영상 / 캐러셀).
4. 한 축에 글이 5개 미만이면 「표본 부족」. 한 번 잘된 것을 규칙으로 만들지 않는다.

## 3. 첫 기록 (2026-11-14 · 글 11개 · 올린 지 1~2일)

- 스레드 조회 3~71, 좋아요 0. 인스타 도달은 영상 둘(105 · 113)만 잡히고 나머지 0.
- 가장 많이 본 글: L0001 목록형(71) · P0004 「세 번 멈췄다」(65) · P0008 영상(48). 가장 적게 본 글: P0010 캐러셀(3) · P0009(10).
- 읽기: **지금은 훅보다 도달이 문제다.** 팔로워가 거의 없는 새 계정이라 글이 보일 자리가 없다. 글을 다듬는 것만으로는 안 바뀐다 — 남의 글에 사람이 직접 다는 답글(자동 댓글은 AGENTS §2-5 로 금지)과 검색에 걸리는 주제 낱말이 먼저다.

## 4. 내놓는 것

3. **다음 주에 바꿀 것 세 가지** — `week-plan` 이 읽는다.
