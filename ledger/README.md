# 소재 장부

글에 쓰는 **사실은 이 장부에 있는 것만**이다. 한 줄에 사건 하나(JSON Lines).

| 칸 | 뜻 |
|---|---|
| `id` | `E` + 번호 (바꾸지 않는다) |
| `app` | `yonghane` · `vocarider` · `wildcrown` · `maker`(만드는 방식 자체) |
| `date` | 사건 날짜 |
| `title` | 한 줄 요약 |
| `facts` | 글에 쓸 수 있는 사실 문장들 — **글의 숫자는 여기에 있는 숫자만** 쓸 수 있다(검사가 대조) |
| `source` | 근거 위치(저장소 경로:줄 · 커밋) |
| `public` | 공개해도 되는가 |

장부에 넣기 전에 근거를 연다. 모델이 낸 「사건」은 근거를 찾기 전까지 넣지 않는다.
