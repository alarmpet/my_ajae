# 통합자 독립 판정 (셋을 읽기 전)
- 1. 「my_ajae」를 보고 드라마를 떠올리는 사람은 일부일 것(추측). 대부분은 「마이 아재」 = 친근한 호칭으로 읽고, 의미 공백이 있어도 표시 이름 「아재도 한다」가 바로 아래에서 채운다. 드라마 연상은 강점도 약점도 크지 않다 — 다만 연상이 안 돼도 손해가 없다.
- 2. made_in_ajae: 정체성(만든다)을 직접 전달. 단점 12자·밑줄 2개, 받아 적기 어렵고, 「made in」은 원산지 표시 말투라 물건/브랜드 느낌 — 사람 기록 계정보다 상점처럼 보일 수 있음(추측).
- 3. 제3안: ajae_makes(10자, 「아재가 만든다」), ajae.dev(8자, 개발 냄새 — 비개발자 콘셉트와 충돌), ajaedo(6자, 「아재도」 — 표시 이름과 일치하나 뜻 약함).
- 4. 맞다. 인스타 · 스레드는 프로필에서 표시 이름 · 소개가 아이디보다 먼저 읽힌다. 아이디는 검색 · 구두 전달 · 멘션 용도.
- 5. 추천: KEEP my_ajae. 틀릴 조건: 유입이 주로 「아이디만 보이는」 곳(쇼츠 워터마크 · 영상 끝 자막 · 멘션)이라 아이디 자체가 뜻을 실어야 하는 경우 → 그때는 ajae_makes 류가 낫다.
